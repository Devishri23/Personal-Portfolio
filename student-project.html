About the Project

Student Management System is a console-based application developed using Core Java, JDBC, and MySQL to manage student records in a structured database.

Key Features

  • Add student records.
  • View student records.
  • Search for a student.
  • Update student information.
  • Delete student records.

Database

MySQL stores student information such as student ID, name, course, email, and marks. JDBC is used to connect the Java application to the database and execute SQL operations.
