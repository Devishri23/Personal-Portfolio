About the Project

This website provides a single place to explore my developer profile, technical skills, academic background, and project work. It is designed to work across desktop and mobile screen sizes.

Key Features

  • Responsive layout for desktop and mobile.
  • Navigation between profile sections.
  • Project cards with individual detail pages.
  • Dark and light theme toggle.
  • Links to GitHub, LinkedIn, and email.
  • Resume download link.

Technologies

HTML structures the content, CSS controls the responsive visual design, JavaScript handles interactive behavior, and Bootstrap Icons provide interface icons.
