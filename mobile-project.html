Mobile Purchase Prediction and Recommendation System

A machine learning-based web application designed to help users assess smartphone affordability against their budget and discover similar smartphones.

Explore Other Projects

About the Project

The system collects a user's budget and selected smartphone specifications, predicts affordability, and provides similar smartphone recommendations. The recommendation process uses K-Nearest Neighbors (KNN) and Euclidean distance to identify nearby records in the selected feature space.

Objectives

  • Estimate smartphone affordability using the user's budget and selected specifications.
  • Apply machine learning classification techniques to the affordability task.
  • Recommend similar smartphones using KNN-based distance comparison.
  • Present prediction results, history and recommendation through a web application.

Main Features

  • User registration and login.
  • Collect user budget and smartphone preferences.
  • Predict affordability from selected input features.
  • Recommend similar smartphones using KNN.
  • Display and store prediction history.
  • Use MySQL for application data storage.

Machine Learning Approach

Classification models explored in the project include Logistic Regression, Decision Tree, and Random Forest. The recommendation component uses K-Nearest Neighbors (KNN) with Euclidean distance to compare smartphone specifications. The final deployed model and evaluation metrics should match the actual model saved in the project.

System Workflow

User registers or logs in
User enters budget and preferred specifications
Affordability model generates a prediction
System displays the affordability result
User requests recommendations and KNN finds similar smartphones
Prediction history is stored in the database

Dataset

The project uses a smartphone dataset sourced from Kaggle. It includes fields such as brand, model, price, RAM, storage, processor, battery, camera specifications, 5G support, and rating. Dataset preprocessing and feature selection are part of the machine learning pipeline.
