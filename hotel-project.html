About the Project

Developing a full-stack Hotel Booking System that allows customers to browse and book hotels, while administrators and hotel managers manage hotel information, facilities, and bookings.

Key Features

  • User registration and login with JWT authentication.
  • Role-based access for Admin, Hotel Manager, and Customer.
  • Hotel management operations: add, update, delete, and view.
  • Location and facility management.
  • Hotel reviews.
  • Booking and booking-status management.
  • MySQL database integration and REST APIs.
  • BCrypt password hashing.
